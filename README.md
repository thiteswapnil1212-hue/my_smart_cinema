# My Smart Cinema

A **cinema ticket-booking demo** — browse movies, pick a show, choose seats, and book.

**Live demo:** https://mysmartcinema.vercel.app/

## Status

Demo/prototype. The happy path (browse → showtime → seats → booking form) works; known limitations: client-side routing only (deep links 404 on refresh), single-seat selection, unvalidated booking form, no real pricing, one hardcoded showtime. No backend — bookings are not persisted.

## Note

This repository currently holds project metadata only; the deployed demo is built and hosted separately.
